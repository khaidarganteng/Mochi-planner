# Mochi Planner 🍡 — Planner serba ada yang imut (Next.js + Tailwind)

Aplikasi produktivitas bertema pastel dengan 6 modul:

| Modul | Fitur |
|---|---|
| Beranda | Sapaan + maskot yang berubah ekspresi, ringkasan harian, cadangan data (ekspor/impor/reset) |
| Tugas | Papan kanban (drag & drop), prioritas, tenggat, pencarian, progres |
| Kebiasaan | Pelacak 7 hari, streak, ikon pilihan |
| Fokus | Timer Pomodoro (jeda/lanjut, bunyi, durasi bisa diatur), statistik 7 hari |
| Keuangan | Pemasukan/pengeluaran, anggaran bulanan, grafik kategori & harian, navigasi bulan |
| Catatan | Sticky note berwarna, pin, pencarian |

Semua data tersimpan di `localStorage` browser (tanpa backend/database).

## Menjalankan
```bash
npm install
npm run dev     # http://localhost:3000
```

## Deploy gratis
Push ke GitHub lalu import di https://vercel.com.
